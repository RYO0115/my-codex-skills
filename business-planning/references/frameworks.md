# 事業モデル設計フレームワーク

## リーンキャンバス(検証段階向け)

- **入力**: 事業アイデア概要、想定顧客像、market-research の顧客分析(あれば)。
- **出力**: 9ブロック+日本の実務慣行に合わせた「リソース」枠を加えた 10 ブロック
  1枚図。

| ブロック | 書くこと |
|---|---|
| 課題 | 上位3つ。既存の代替手段も併記 |
| 顧客セグメント | ビーチヘッド(最初に獲る一点)を太字で |
| 独自の価値提案 | 1文。誰に・何が・なぜ自社か |
| ソリューション | 課題1つにつき1機能まで |
| チャネル | 顧客に届く経路(無料/有料の別) |
| 収益の流れ | 価格モデルと根拠 |
| コスト構造 | 固定費/変動費の主要項目 |
| 主要指標 | 検証段階で追う数値(AARRR のどこか) |
| 圧倒的優位性 | 真似できないもの(なければ「なし」と正直に) |
| リソース(日本版追加枠) | 使える人・金・資産・関係。社内起案で必ず問われる |

- 各ブロックは**仮説**。確度(検証済み/未検証)ラベルを付け、未検証の最重要
  仮説(リスキーな仮説)を1つ特定して検証計画につなげる。

## Ansoff マトリクス(参入計画の方向決め)

- **入力**: 現行製品・現行市場の実績、成長目標。
- **出力**: 4象限のうちどれで成長するかの選択+リスク評価。

| | 既存製品 | 新製品 |
|---|---|---|
| **既存市場** | 市場浸透(低リスク) | 新製品開発(中リスク) |
| **新市場** | 新市場開拓(中リスク) | 多角化(高リスク) |

- 対角(多角化)に行くほど失敗率が上がる。多角化を選ぶ場合は「なぜ隣の象限では
  だめか」を必ず書かせる。海外展開は「新市場開拓」— [market-entry.md](market-entry.md) へ。

## STP → 4P

- **入力**: market-research のセグメント分析(Kotler 5基準スコア済み)。
- **出力**:
  1. **S**: 採用するセグメント区分(調査から引用、再発明しない)
  2. **T**: 優先ターゲット1つ(複数選ぶのは選んでいないのと同じ)
  3. **P**: ポジショニングステートメント 1文 —
     「〈ターゲット〉にとって、〈製品〉は〈競合代替〉と違い〈独自価値〉を提供する。
     なぜなら〈根拠〉」
  4. その後 4P(製品・価格・流通・販促)に展開 → 詳細は [gtm-strategy.md](gtm-strategy.md)

## ビジネスモデルキャンバス(フル事業計画向け)

リーンキャンバスの拡張版(パートナー・主要活動・主要リソース・顧客との関係を
追加した9ブロック)。社外パートナーや既存事業とのシナジーが計画の骨子になる
場合(JTC の新規事業起案など)はこちらを使う。
