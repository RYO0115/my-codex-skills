# GTM(Go-to-Market)戦略

固定パイプライン: **セグメント → ICP → ポジショニング → チャネル → 価格 → ローンチ計画**。
前段を飛ばして価格やチャネルから議論を始めない。

## 1. ビーチヘッドセグメントと ICP

- market-research の優先セグメントから、**最初に獲る一点(ビーチヘッド)**を選ぶ。
- ICP(Ideal Customer Profile)を定義する:
  - 属性: 業種・規模・地域・使用技術
  - 状況: トリガーイベント(何が起きたら買うモードに入るか)
  - 除外条件: 売らない相手(サポート過多・解約率高の予兆)も明記する
- B2B は購買委員会(決裁者/推進者/利用者/情報システム)ごとの関心事を分ける。

## 2. ポジショニングとメッセージング

- ポジショニングステートメント([frameworks.md](frameworks.md) の STP 形式)を確定。
- メッセージングは階層で作る: 1行(タグライン)→ 3つの柱(ベネフィット+証拠)
  → 反論処理(想定される「でも○○でしょ」への答え)。
- 競合との比較軸は「勝てる軸」を自分で選ぶ(競合分析マトリクスの
  勝てる領域から引用)。

## 3. チャネル戦略

- 候補: インバウンド(SEO/コンテンツ)、アウトバウンド(営業)、PLG(セルフサーブ)、
  パートナー/代理店、マーケットプレイス、コミュニティ、広告。
- 選定基準: ICP がいる場所か / 単価と CAC が釣り合うか(低単価×人的営業は
  成立しない)/ 自社リソースで回るか。
- **最初は 1〜2 チャネルに集中**。各チャネルに 90 日の検証指標を付ける
  (例: 商談化率、CVR、CAC 実測)。

## 4. 価格戦略

- アンカー: 競合実勢(サブエージェントに料金ページ+レビューでの価格不満を
  収集させる)と、顧客の得る価値(節約時間・増収額)の 1/10 目安。
- モデル選択: 定額 / 従量 / 席数 / 成果報酬 / フリーミアム。ICP の予算の出どころ
  (経費か投資か)に合わせる。
- 価格は仮説として設定し、検証方法(提案時の反応率など)をセットで書く。
- 価格が決まったら [financials.md](financials.md) のユニットエコノミクスで健全性を検算する。

## 5. ローンチ計画

- ローンチは点でなく期間: プレローンチ(ウェイトリスト・先行顧客)→ ローンチ
  (発表・初期顧客獲得)→ ポストローンチ(事例化・改善ループ)。
- 各フェーズに 成功指標 / 担当 / 期限 を付け、[risk-and-roadmap.md](risk-and-roadmap.md)
  の 90 日ロードマップに落とす。
