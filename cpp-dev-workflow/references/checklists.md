# チェックリスト

各節目で該当リストを**上から順に全項目**確認する。1つでも未達なら次の工程へ進まない。

## 機能1つの実装完了時

- [ ] 実装**前**に正常系・異常系のテストを書いた(テストファースト)
- [ ] 新規テストが全部グリーン
- [ ] 既存テスト**全件**がグリーン(`ctest --test-dir build --output-on-failure`)
- [ ] clang-tidy が警告ゼロ(変更ファイルに対して実行)
- [ ] マルチスレッドコードを触った場合: TSan ビルドでもテストがグリーン
- [ ] ハードコード・グローバル変数を追加していない(必要だった場合は報告済みで承認を得ている)
- [ ] 既存コードと重複する実装がない
- [ ] `clang-format -i` を変更ファイルに実行した

## PR 提出前

- [ ] 既存テスト全件がグリーン(リグレッション)
- [ ] `run-clang-tidy -p build` が全ファイルで警告ゼロ
- [ ] CMakeLists.txt のバージョンを更新した(versioning.md の規則で桁を選択)
- [ ] `-Werror` 付きでビルドが通る
- [ ] 新規ファイルを CMakeLists.txt に追加した(GLOB を使っていないため手動列挙)
- [ ] 公開ヘッダのインクルードガード形式が正しい
- [ ] コミットに生成物(build/ など)が含まれていない

## 設計段階(実装開始前)

- [ ] 既存コードを調査し、重複する機能がないことを確認した
- [ ] モジュール間の依存が一方向であることを確認した(循環参照なし)
- [ ] 外部依存(I/O・デバイス・時刻)がインターフェース経由で注入され、テストでモック可能
- [ ] ハードコード・グローバル変数が必要な場合、理由をユーザーに報告して指示を受けた
