# HTML報告Artifact

報告内容を、ローカルブラウザで確実に開ける単一HTMLファイルとして納品する。

## 必須条件

- `<!doctype html>`、`html`、`head`、UTF-8の`meta charset`、viewport、`title`、`body`を持つ完全な文書にする。
- CSSは文書内へ置き、外部CDN、外部フォント、ビルド処理、JavaScriptを必須にしない。
- 狭い画面でも横スクロールなしで主要本文を読めるようにする。長いURLやコードは折り返す。
- 実測値、変更内容、未完了事項を分け、未実施の操作を完了済みと書かない。
- 保存後にHTMLパーサで構文を確認し、実ブラウザでファイルを開いて、タイトル・主要見出し・本文の表示と横方向のはみ出しを確認する。
- 検証に失敗したHTMLをArtifactとして報告しない。修正して再検証する。

## 納品

検証済みHTMLの絶対パスをユーザーへ提示する。チャット本文にも結論と検証結果を短く併記し、HTMLを開けない場合でも結果が分かるようにする。
