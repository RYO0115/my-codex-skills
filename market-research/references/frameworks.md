# 分析フレームワークと適用順序

## 適用順序の原則(固定)

**外側から内側へ**絞り込む。自己流の順序で分析を始めない。

```
PEST(LE)  →  業界構造(Five Forces)/ 3C  →  SWOT  →  (必要なら)市場規模・顧客分析
マクロ環境      業界・競合・自社の相対関係       統合        定量化・深掘り
```

SWOT は独立の分析ではなく、PEST・3C の**出力を入力とする統合ステップ**。
先に SWOT から書き始めるのは典型的な失敗パターン。

## 各フレームワーク(入力 → 出力)

### PEST(LE)分析
- **入力**: 政治(規制・政策)/ 経済(景気・為替・所得)/ 社会(人口動態・価値観)/
  技術(技術革新・普及率)、必要に応じ法律・環境。
- **出力**: 各要因が対象事業に与える「機会 / 脅威」のリスト。各項目に出典を付ける。
- **コツ**: 要因の羅列で終わらせず、各項目に「だから何か(So What)」を1行書く。

### 3C分析
- **入力**: 顧客(Customer: 市場規模・ニーズ・購買行動)、競合(Competitor: 強み弱み・
  シェア)、自社(Company: リソース・技術・チャネル)。
- **出力**: 自社が勝てるポジションの仮説。STP・GTM 立案の前段になる。

### Porter's Five Forces
- **入力**: 既存競合の競争度 / 新規参入の脅威 / 代替品の脅威 / 買い手の交渉力 /
  売り手の交渉力、それぞれの業界データ。
- **出力**: 業界の収益構造と競争激化度の評価(各力を 強/中/弱 で判定+根拠)。
  「この業界は構造的に儲かるか」への答え。

### SWOT分析
- **入力**: 内部要因(強み・弱み=3Cの自社分析から)、外部要因(機会・脅威=PEST/
  Five Forces から)。
- **出力**: 2×2 グリッド(各象限 3〜5 項目)+クロス SWOT(SO/WO/ST/WT)の戦略
  オプション。各項目は数字・固有名詞・具体例を伴うこと(曖昧さテスト対象)。

### 競合分析マトリクス
- **入力**: 競合 3〜7 社の 製品機能 / 価格体系 / ターゲット顧客 / メッセージング /
  流通チャネル / 直近の動き(資金調達・リリース)/ 口コミでの不満点。
- **出力**: 項目別比較表+「勝てる領域 / 負ける領域 / 差別化ポイント」の3点整理。
- **サブエージェント指示のコツ**: 抽出項目(表の列)を明示的に列挙して渡すと精度が
  上がる。「各社について機能・価格帯・ターゲット顧客・メッセージングを抽出せよ」の形。
