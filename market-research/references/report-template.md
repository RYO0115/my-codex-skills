# 市場調査レポート雛形と品質ゲート

出力先: `knowledge/research/<slug>/market-research-YYYY-MM-DD.md`
あわせてヒアリング結果・市場定義を `knowledge/research/<slug>/context.md` に保存する
(次回調査と business-planning スキルが再利用する)。

## レポート構成

```markdown
---
title: <対象市場> 市場調査
created: YYYY-MM-DD
status: draft   # draft → final
purpose: <参入判断 / 事業計画裏付け / 競合ウォッチ / ...>
---

# <対象市場> 市場調査

## エグゼクティブサマリー(3行)
<結論を先に。参入推奨 / 見送り / 条件付き のいずれかを明言する>

## 調査の前提
- 市場定義: <地域 × 顧客層 × 製品カテゴリ>
- Key Questions: <この調査が答える問い 3〜6 個>
- 調査日・調査体制: <日付、サブエージェント分担>

## 1. マクロ環境(PEST)
<機会/脅威リスト。各項目に So What と出典>

<各力の 強/中/弱 判定+根拠>

<トップダウン・ボトムアップ両方の算出過程と突き合わせ結果。
 全数値に 方法+前提+出典+信頼度 を併記(market-sizing.md の形式)>

## 4. 競合分析
<比較マトリクス+勝てる領域/負ける領域/差別化ポイント>

## 6. 反証・リスク(削除不可)

## 出典一覧
<一次/二次に分けて列挙。URL+発行年+取得日>
```

## 品質ゲート(納品前セルフチェック)

全て Yes になるまで `status: final` にしない:

- [ ] **曖昧さテスト**: 数字・固有名詞・具体例のない主張が残っていないか
  (「市場は成長している」→ 何%で、誰の統計か)
- [ ] 全ての定量値に 方法+前提+出典+信頼度 が付いているか
- [ ] TAM/SAM/SOM は 2 方式で三角測量したか(できない場合、単一ソースと明記したか)
- [ ] 反証セクションが実質的な内容を持っているか(1行の言い訳で済ませていないか)
- [ ] 二次情報単独で断定している数値がないか
- [ ] エグゼクティブサマリーが「見送り」も選択肢として検討した形跡があるか
- [ ] `context.md` を更新したか
