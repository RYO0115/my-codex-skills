# 委譲判断

次の条件をすべて満たす場合だけ委譲する。

1. ユーザーまたは適用中の規約がサブエージェント利用を許可している。
2. タスクが独立しており、親が結果を待たずに別の有益な作業を進められる。
3. 目的、対象範囲、成果物、禁止事項、検証方法を短い指示で閉じられる。
4. 書き込み範囲が親や他エージェントと重ならない。
5. 起動・説明・レビューのコストを、並列化または文脈圧縮の効果が上回る。

モデルは既定で親から継承する。ユーザーが指定した場合、または速度・費用・専門性に
明確な理由がある場合だけ、利用可能なCodexモデルへ上書きする。モデル名をスキルへ
固定しない。利用可能なモデルは製品側で変わり得るためである。

委譲しやすい例:

- 4つの市場観点を独立して調査し、各結果を表形式で返す
- 20ファイルへの同じ機械変換を、親と重ならない範囲で適用する
- 親が実装中に、別エージェントが仕様との不一致だけを調べる

委譲しない例:

- 次に編集する関数の仕様確認
- 1ファイルの小修正
- ユーザーの曖昧な意図を確定する判断
- 同じテストを親とサブエージェントの両方が実行する二重確認
